#  Veille technologique — Combien de choses votre téléphone sait-il sur vous en une seule journée ?

Dans le cadre de ma formation en BTS SIO, spécialité SISR (Solutions d'Infrastructure, Systèmes et Réseaux), j'ai choisi de réaliser une veille technologique sur les données générées par notre smartphone au quotidien. Le sujet de ma veille est : « Combien de choses votre téléphone sait-il sur vous en une seule journée ? ». Aujourd'hui, le smartphone est devenu un outil indispensable dans notre vie quotidienne. Nous l'utilisons pour communiquer, nous déplacer, regarder des vidéos, utiliser les réseaux sociaux, consulter nos comptes bancaires, effectuer des achats, écouter de la musique, travailler ou encore suivre notre activité physique. Toutes ces utilisations peuvent entraîner la génération, la collecte, la transmission ou le stockage de différentes données. L'objectif de cette veille est donc de comprendre quelles informations peuvent être générées par l'utilisation d'un smartphone, comment ces données circulent sur les réseaux, où elles peuvent être stockées et quels sont les risques liés à leur sécurité.

##  Problématique

La problématique principale de ma veille est : « Comment les smartphones collectent-ils, transmettent-ils et stockent-ils les données de notre quotidien, et comment pouvons-nous protéger ces données ? ». Cette problématique permet de faire le lien entre l'utilisation quotidienne d'un smartphone et plusieurs domaines de l'informatique, notamment les réseaux, les serveurs, le cloud computing, la cybersécurité et la protection des données personnelles.

##  Les données générées au quotidien

Un smartphone peut générer différentes catégories de données au cours d'une journée. Parmi celles-ci, on peut retrouver les données de localisation, les informations liées aux connexions réseau, les applications utilisées, le temps d'utilisation, certaines données de navigation, les informations techniques de l'appareil et les données synchronisées avec des services cloud.

Par exemple, lorsqu'un utilisateur utilise une application de navigation, son smartphone peut utiliser des informations de localisation afin de déterminer sa position et de calculer un itinéraire. Lorsqu'il se connecte à un réseau Wi-Fi, son appareil communique avec l'infrastructure réseau afin d'accéder à Internet. Lorsqu'il utilise une application de messagerie ou un réseau social, son smartphone échange des informations avec les serveurs de l'application. Enfin, lorsqu'il utilise un service cloud, certaines données peuvent être synchronisées avec des serveurs distants.

##  Une journée avec son smartphone

Pour rendre cette veille plus concrète, j'ai choisi de suivre une journée classique d'un utilisateur.

Le matin, au réveil, l'utilisateur consulte son smartphone pour regarder l'heure, ses notifications, la météo ou ses messages. Le téléphone est déjà connecté à un réseau et certaines applications peuvent fonctionner en arrière-plan selon les autorisations et les paramètres configurés.

Lors du déplacement vers l'école ou le travail, l'utilisateur peut utiliser une application de navigation. Des informations liées à la localisation peuvent alors être utilisées pour fournir un itinéraire ou certaines fonctionnalités. Les données peuvent suivre un parcours simplifié : smartphone, réseau mobile ou Wi-Fi, Internet, serveur de l'application et éventuellement stockage dans le cloud.

Une fois arrivé à destination, le smartphone peut se connecter à un réseau Wi-Fi. Cette connexion permet d'aborder plusieurs notions importantes du BTS SIO SISR comme l'adressage IP, le DHCP, le DNS, le Wi-Fi, le routage, les routeurs, les pare-feu et les réseaux locaux.

Dans la journée, l'utilisateur peut également utiliser des applications de réseau social, de messagerie, de streaming ou des services bancaires. Ces applications communiquent avec des serveurs distants afin d'envoyer ou de récupérer des informations. Une représentation simplifiée du fonctionnement est la suivante :

📱 Smartphone → 📡 Wi-Fi / réseau mobile → 🌐 Internet → 🖥️ Serveur → 🗄️ Base de données / ☁️ Cloud

Chaque utilisation peut donc entraîner différents échanges de données.

##  Le rôle des réseaux

Les réseaux jouent un rôle essentiel dans la circulation des données d'un smartphone. Lorsqu'un téléphone accède à Internet, il communique avec différents équipements et services. Il peut être connecté à un point d'accès Wi-Fi ou à une antenne de téléphonie mobile. Les données passent ensuite par différentes infrastructures réseau avant d'atteindre le serveur du service utilisé.

Un schéma simplifié peut être représenté ainsi :

📱 Smartphone  
↓  
📡 Wi-Fi / 4G / 5G  
↓  
🌐 Internet  
↓  
🔥 Routeur / Pare-feu  
↓  
🖥️ Serveur distant  
↓  
🗄️ Base de données / ☁️ Cloud

Cette partie de la veille permet d'étudier plusieurs notions liées au SISR comme les adresses IP, le DHCP, le DNS, le routage, les réseaux Wi-Fi, les protocoles de communication, les pare-feu et la sécurisation des échanges.

##  Le cloud et le stockage des données

Les données utilisées par un smartphone ne sont pas forcément stockées uniquement sur l'appareil. De nombreux services utilisent le cloud afin de sauvegarder ou synchroniser certaines informations.

Par exemple, les photos, fichiers, sauvegardes ou paramètres peuvent être synchronisés avec des serveurs distants. Cela permet à un utilisateur de retrouver ses informations depuis plusieurs appareils.

Le fonctionnement peut être représenté de manière simplifiée :

📱 Smartphone → 🌐 Internet → ☁️ Cloud → 🗄️ Serveurs

Cette partie de ma veille me permet donc de m'intéresser au fonctionnement du cloud computing, au stockage distant, à la synchronisation et à la sécurité des données stockées sur des serveurs.

##  Les risques liés aux données

La quantité de données générées par les smartphones soulève également des questions de cybersécurité. Les données peuvent être exposées à différents types de menaces.

Le phishing représente l'une des menaces courantes. Il consiste à tromper un utilisateur afin de récupérer des informations comme ses identifiants. Un exemple de fonctionnement peut être représenté ainsi :

👤 Utilisateur → 📧 Message frauduleux → 🔗 Faux site → 🔑 Identifiants

Les smartphones peuvent également être concernés par des applications malveillantes, des vulnérabilités, le vol de comptes ou des fuites de données. L'utilisation d'un réseau Wi-Fi non sécurisé peut également présenter des risques.

Un compte compromis peut donner accès à différentes informations associées au service. C'est pourquoi la sécurisation des comptes et des appareils est importante.

##  Les solutions de protection

Plusieurs bonnes pratiques permettent de réduire les risques liés aux données personnelles.

Il est important d'utiliser des mots de passe uniques et suffisamment complexes pour les différents comptes. L'authentification multifacteur permet également d'ajouter une couche de sécurité supplémentaire.

Les mises à jour du système du smartphone et des applications doivent également être effectuées régulièrement afin de bénéficier des correctifs de sécurité disponibles.

Il est également conseillé de vérifier régulièrement les autorisations accordées aux applications. Une application peut par exemple demander l'accès à la localisation, au microphone, à l'appareil photo ou aux contacts. L'utilisateur doit donc vérifier si ces autorisations sont réellement nécessaires.

Il est également important de faire attention aux réseaux Wi-Fi utilisés, de privilégier des connexions sécurisées et d'éviter de communiquer des informations sensibles sur des réseaux inconnus.
